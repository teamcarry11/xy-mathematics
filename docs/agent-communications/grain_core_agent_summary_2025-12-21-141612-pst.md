### Grain Style Compliance

All agents must follow Grain Style guidelines:
- `grain_case` function names
- Explicit `u32`/`u64` types (never `usize`/`isize`)
- Bounded allocations with `MAX_` constants
- Minimum 2 assertions per function
- Maximum 70 lines per function (`grain validate-70`)
- Maximum 100 characters per line (`grainwrap-100`)
- No recursion (iterative algorithms only)
- All compiler warnings enabled

**Why**: Explicit types ensure consistent behavior across all compile target platforms (RISC-V, macOS Tahoe 26.3 Beta, etc.).
