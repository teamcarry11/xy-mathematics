# Core Coordination System: Instructions for All Agents

## Overview

You now have a dedicated coordination file at `docs/core-coordination/core-coordination_{your_agent_name}.md` that serves as your real-time communication channel with Core Agent and other agents. This file helps synchronize cross-agent progress and prevent conflicts before they happen.

## Why This Matters

When we work together with clarity and coordination, we build something greater than any single agent could create alone. Your coordination file is your voice in our collective effort—it helps Core Agent understand your current state, your needs, and how you're contributing to our shared vision.

This system exists because we believe in:
- **Transparency**: Everyone can see what everyone else is working on
- **Prevention**: We catch integration issues early, before they become problems
- **Collaboration**: We make it easy to find opportunities to work together
- **Efficiency**: Lightweight updates without formal overhead

## Your Coordination File

**Location**: `docs/core-coordination/core-coordination_{your_agent_name}.md`

**What to Include**:
1. **Current Status**: What you're working on right now
2. **Progress Updates**: Recent completions, milestones reached
3. **Integration Points**: Where you're connecting with other agents
4. **Dependencies**: What you need from others to proceed
5. **Upcoming Work**: What's next on your horizon
6. **Coordination Needs**: When you need to check in with Core or other agents

**How to Update**:
- Overwrite the entire file each time you update it
- Don't worry about preserving history—Core Agent tracks that in coordination plans
- Be concise but complete—aim for clarity over comprehensiveness
- Update whenever your status changes meaningfully

## The Pattern

Think of your coordination file as a living snapshot of your current state. Each time you update it, you're saying: "Here's where I am now, here's what I'm doing, here's how I fit into our collective work."

This isn't about reporting—it's about staying connected. When you share your status, you're helping the whole system work better together.

## Integration with Your Workflow

At the end of each work session, update your coordination file. This ensures Core Agent always has the latest picture of where you are and what you need. It's a small habit that makes a big difference in our collective coordination.

---

**Remember**: This file is yours to maintain. Overwrite it completely each time—no need to preserve old information. Core Agent uses these files to create comprehensive coordination plans, so your fresh updates help everyone stay synchronized.
